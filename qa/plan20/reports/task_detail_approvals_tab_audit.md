# Phase 177 — 태스크 상세 내 승인/신청(Approvals) 탭 검수 결과

## 검수한 항목
- `승인/신청` 탭 내비게이션 및 내부 렌더링 확인
- 4가지 주요 신청서(야근, 기한 연장, 일정 조정, 인력 지원) 버튼 UI 존재 유무
- 신청서 버튼 클릭 시 팝업되는 `ScheduleRequestModal` 표출 여부
- 모달 내 데이터 입력(사유, 필요시 희망일정) 및 제출 동작 연동
- 모달의 취소 및 닫기 동작 유효성

## 정상 확인 (코드 기반 이벤트 분석)
- **탭 및 트리거 버튼 렌더링**: '승인/신청' 탭 진입 시 시각적으로 명확한 4개의 격자형 카드 버튼(추가 작업시간 신청, 마감일 연장 신청, 일정 조정 요청, 인력 지원 요청)이 올바르게 렌더링 됨.
- **모달 표출 및 분기 처리**: 각 버튼 클릭 시 파라미터(`type`)가 정상적으로 전달되어 `ScheduleRequestModal`이 열리며, 타입에 따라 모달 제목과 아이콘, 그리고 입력받는 폼(예: 날짜 필드 노출 여부)이 동적으로 잘 분기됨을 확인함.
- **유효성 검사 및 제출 동작**: 사유(reason) 미입력 시 제출을 방어하며, 일정 조정의 경우 '시작일 > 마감일' 역전 방어 로직이 적용됨. 유효한 입력 제출 시 `addRequest`를 통해 Store에 접수되고 PM에게 알림이 발송되는 데이터 트랜잭션이 원활함.
- **취소/X 버튼 동작**: 내부 닫기 버튼들이 `onClose` 핸들러와 올바르게 매핑되어 모달을 정상 종료함.

## 오류/의심사항
- **[ISSUE-PLAN20-177-001] 모달 Backdrop 외부 영역 닫기 미동작**
  - 앞선 두 개의 모달(PM Dispatch, Task Detail)에서 발견된 것과 완벽히 동일한 패턴의 누락입니다.
  - `ScheduleRequestModal`의 최외곽 딤(Dim) 영역인 `<div className="fixed inset-0 ...">`에 `onClick={onClose}` 이벤트가 바인딩되어 있지 않아, 사용자가 바탕화면 빈 곳을 클릭하여 편하게 창을 닫는 UX가 차단되어 있습니다.

# Phase 174 — 세부 공정 태스크 상세 모달(Task Detail Modal) UI 검수 결과

## 검수한 항목
- 태스크 카드 클릭 시 모달 진입 및 헤더 영역(상태 뱃지, 제목, 담당자 등) 확인
- 진행률 업데이트 슬라이더(Slider) UI 확인
- 산출물(Artifacts) 업로드 컴포넌트 및 목록 확인
- 작업 내역(Work Segments) 추가 폼 UI 확인
- 코멘트/메모 필드 확인
- 모달 취소/닫기 버튼 및 외부(Backdrop) 클릭 동작 확인

## 정상 확인 (코드 기반 렌더링 분석)
- **탭(Tab) 기반 모달 구조**: `OVERVIEW`, `WORK_SEGMENTS`, `PROGRESS`, `ARTIFACTS` 등 정보 단위별로 탭이 쪼개져 있어 UI 복잡도를 훌륭하게 통제함.
- **헤더 영역**: 태스크명(다국어 감지), 프로젝트 ID, 태스크 현재 상태(status), 그리고 Health Score가 모달 최상단에 올바르게 노출됨.
- **진행률 슬라이더 & 코멘트**: `PROGRESS` 탭 내에 `<input type="range">` 형태의 직관적인 슬라이더가 5% 단위(step)로 배치되어 있으며, 변경 사유를 적을 수 있는 `textarea` 메모 폼이 렌더링됨.
- **산출물(Artifacts)**: 드래그 앤 드롭 영역 및 파일 선택 버튼(`<input type="file">`)이 정상적으로 바인딩되어 있으며 업로드 된 파일 리스트 표출 로직이 온전함.
- **세부 작업 내역(Work Segments)**: 시작일, 종료일, 작업 내용을 입력하는 인라인 폼이 존재하며 입력 후 '추가' 버튼과 정상 연동되어 있음.

## 오류/의심사항
- **[ISSUE-PLAN20-174-001] 헤더(Header) 내 담당자 정보 누락**
  - 명세서에는 모달 헤더에 담당자(Assignee)가 표출될 것을 지시하고 있으나, 실제 구현은 헤더에는 없고 첫 번째 탭인 `OVERVIEW` 내부 영역에 표기되어 있어 즉각적인 작업자 식별이 아쉽습니다.
- **[ISSUE-PLAN20-174-002] 외부 영역(Backdrop) 클릭 시 닫기 미동작**
  - Phase 168의 PM Dispatch 모달과 완벽히 동일한 이슈로, 모달을 감싸는 최외곽 배경 레이어(`fixed inset-0 bg-black/50`)에 `onClick={onClose}` 이벤트 핸들러가 누락되어 있습니다. 사용자가 창 밖을 클릭해도 모달이 닫히지 않아 불편함을 야기할 수 있습니다.

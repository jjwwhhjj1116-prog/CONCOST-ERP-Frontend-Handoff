# Phase 171 — 파트별 보드 드래그 가능 영역 및 제약 검수 결과

## 검수한 항목
- 파트 간(예: 구조팀 ↔ 건축팀) 이동 차단 여부 확인 (Drag and Drop)
- 동일 파트 내 상태 컬럼 간 이동 허용 확인
- 이동 시 권한(작업자 본인 또는 PM 여부) 체크 확인

## 정상 확인 (코드 기반 렌더링 분석)
- **해당 사항 없음**: `ProjectPartBoard` 뷰에서는 기능이 구현되지 않아 정상 작동 여부를 판단할 요건이 충족되지 않음.

## 오류/의심사항 (기획 불일치 및 기능 누락)
- **[ISSUE-PLAN20-171-001] Drag and Drop (DND) 기능 전면 미구현**
  - 컴포넌트(`src/components/board/ProjectPartBoard.tsx`) 코드를 정밀 분석한 결과, HTML5의 `draggable` 속성이나 `onDragStart`, `onDrop`, `onDragOver` 등의 드래그 앤 드롭 이벤트 핸들러가 **전혀 존재하지 않습니다.**
  - Phase 170에서 지적된 바와 같이, '상태별 컬럼(대기 중, 진행 중 등)' 레이아웃이 뷰(Swimlane)에서 배제되면서 상태 이동을 위한 드래그 타겟 영역 자체가 설계에서 빠진 것으로 파악됩니다.
  - 이로 인해 기획상 요구된 "다른 파트로의 이동 차단" 및 "상태 업데이트 권한 체크" 로직 역시 컴포넌트 내에 탑재되어 있지 않아 검수 진행이 원천 불가능합니다.

## 증빙
- 자동화 브라우저 봇 제약(Quota Limit)으로 소스코드 검색으로 대체.
- 참조 코드 검색 결과: `src/components/board/ProjectPartBoard.tsx` 파일 내 `draggable` 및 `onDrag` 키워드 검색 시 일치 항목 **0건** 확인 (해당 컴포넌트는 오직 'Read-Only' 목록 형태로만 렌더링됨).

# Phase 172 — 세부 공정 View 진입 및 탭/구조 검수 결과

## 검수한 항목
- 세부 공정 View로 뷰 모드 전환
- 컬럼 구성 확인: `계획/스케치` → `모델링` → `도면화` → `검토/수정`
- 각 단계별 설명 툴팁(hover) 표출 확인
- 단계별 카운트 및 진행률 바(progress bar) 시각화 확인

## 정상 확인 (코드 기반 렌더링 분석)
- **화면 진입 및 뷰 모드 전환**: `page.tsx`에서 드롭다운을 통해 `DETAILED`(세부 공정 View) 모드로 진입 시, `Board` 컴포넌트가 칸반 레이아웃을 성공적으로 렌더링하도록 바인딩되어 있음.
- **카운트 표시 및 텍스트 렌더링**: 각 컬럼 상단에 태스크 개수 카운트 뱃지(`{tasks.length}`)와 평균 진행률 수치(텍스트 형태)가 올바르게 렌더링됨.

## 오류/의심사항 (기획 불일치 및 기능 누락)
- **[ISSUE-PLAN20-172-001] 기획과 불일치하는 상태(Stage) 컬럼 구성**
  - 명세서상 요구된 `계획/스케치`, `모델링`, `도면화`, `검토/수정` 4단계 컬럼 대신, 실제 구현 코드는 `작업 착수 전`, `QC/PM작업착수`, `진행 중`, `PM검토`, `QC검토`, `완료` 의 6단계로 하드코딩 되어 있습니다. (완전히 다른 프로세스 설계가 반영됨)
- **[ISSUE-PLAN20-172-002] 단계별 설명 툴팁(Hover Tooltip) 미구현**
  - 컬럼 헤더(`Column.tsx`) 소스코드에 마우스 오버 시 표시되어야 할 설명 툴팁 요소(HTML `title` 속성 또는 Tooltip 컴포넌트)가 누락되어 있습니다.
- **[ISSUE-PLAN20-172-003] 컬럼 진행률 '바(Bar)' 그래픽 누락**
  - 기획에서 지시한 '진행률 바(progress bar) 시각화' 대신, 텍스트 형태(`<span>평균 xx%</span>`)로만 간략하게 표기되고 있어 시각적 UI 기획과 어긋납니다.

- 참조 코드 2: `src/components/board/Column.tsx` 렌더링 구조 확인 (툴팁 및 프로그래스 바 DOM 엘리먼트 부재).

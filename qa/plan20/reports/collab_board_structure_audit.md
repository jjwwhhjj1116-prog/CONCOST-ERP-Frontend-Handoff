# Phase 178 — 협업 보드(Collab View) 진입 및 구조 검수 결과

## 검수한 항목
- `협업 보드 View` 뷰 모드 전환 확인
- 컬럼 구성 확인: `수주/대기` → `CONCOST` → `VIET_QS` → `QC/검수` → `완료`
- 외주/협업 관련 특화 데이터 표출 여부 확인 (외주 비용, 정산 상태 등)
- 컬럼별 태스크 카드 렌더링 확인

## 정상 확인 (코드 기반 렌더링 분석)
- **뷰 전환 및 컬럼 구조**: `page.tsx`에서 뷰 타입을 변경 시 `Board` 컴포넌트가 `COLLAB_COLUMNS` 상수를 정상 렌더링하여, 기획에 정의된 `수주/대기` → `CONCOST` → `VIET_QS` → `QC/검수` → `완료` 순서대로 5단계 컬럼 레이아웃을 정확하게 표출함.
- **카드 렌더링**: 각 컬럼의 성격(상태)에 맞는 `TaskCard` 필터링이 올바르게 동작하며 카드가 칸반 내부에 잘 나열됨.

## 오류/의심사항 (기획 불일치 및 기능 누락)
- **[ISSUE-PLAN20-178-001] 외주/협업 특화 데이터(비용/정산 등) 노출 전면 누락**
  - 기획 상 협업 보드(Collab View)는 단순 공정 관리를 넘어 외부 파트너(외주처)와의 협업 및 정산 상태를 조망할 수 있어야 하므로, 카드 내에 '외주 비용', '정산 상태', '협력사 정보' 등이 노출되어야 합니다.
  - 하지만 태스크 카드를 렌더링하는 `TaskCardItem.tsx` 컴포넌트 내부를 분석한 결과, 일반 뷰(세부 공정 보드)와 동일한 공통 컴포넌트를 아무런 조건부 렌더링(뷰 타입에 따른 추가 정보 노출 로직) 없이 재사용하고 있습니다.
  - 이로 인해 협업 보드에서 필수적으로 보여야 할 비용 및 정산 데이터가 렌더링 계층에 아예 존재하지 않습니다.

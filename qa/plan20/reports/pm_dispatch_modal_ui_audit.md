# Phase 168 — PM Dispatch Modal 1차 UI 검수 결과

## 검수한 항목
- 모달 제목/설명 확인
- 작업자 선택 필드 확인
- TaskCard 생성 필드 구조 및 다중 생성 지원 여부 확인
- 작업 기간(시작일/마감일) 입력 확인
- 업무 내용 입력 확인
- 한국어/베트남어 다국어 입력 및 번역 지원 확인
- 필수값 누락 등 Validation 시나리오 확인
- 취소/닫기 및 Backdrop 클릭 방어 로직 확인

## 정상 확인 (코드 기반 렌더링 분석)
- **모달 기본 UI**: 'PM 업무 하달 (Task Dispatch)' 제목과 함께 하달할 프로젝트 정보(최종 기한, PM 정보)가 Alert Box 형태로 명확히 안내됨.
- **다중 Task 생성 구조**: 한 번의 하달로 1개 이상의 세부 업무(Task)를 일괄 생성하여 복수의 작업자에게 배분할 수 있는 '업무 추가' 동적 폼 구조가 잘 구현되어 있음.
- **작업자 선택 및 일정 필드**: Active 상태인 모든 직원을 배정할 수 있는 드롭다운과, 시작일/마감일 Date Picker가 각 Task 행마다 정상적으로 렌더링됨.
- **다국어 입력 및 실시간 번역**: 업무명(Title) 필드에 한국어나 베트남어 입력 시 실시간으로 언어를 감지하며, '자동번역' 버튼 클릭을 통해 타겟 언어로 즉각 번역되는 기능(i18n)이 구현됨.
- **엄격한 Validation**: 
  - 필수값(업무명, 담당자, 날짜) 누락 시 Alert 창으로 저장 차단됨.
  - 시작일이 마감일보다 늦은 경우 에러 Alert 방어 적용됨.
  - 생성하려는 업무 마감일이 프로젝트 최종 납품 기한을 초과할 경우 `window.confirm`으로 사용자에게 1차 경고를 제공함.

## 오류/의심사항
- **[ISSUE-PLAN20-168-001] 업무 상세 내용(Description) 입력 UI 누락**
  - 컴포넌트 State 로직 내에는 `description`과 `scopeName` 필드가 존재하나, 실제 사용자가 입력할 수 있는 화면 상의 `textarea`나 `input` 필드가 모달 UI에서 렌더링 되지 않고 있음. 업무명(Title) 1줄 텍스트로만 업무를 지시해야 하는 한계가 존재함. (요구사항 재확인 또는 UI 추가 필요)
- **[ISSUE-PLAN20-168-002] 외부 영역(Backdrop) 클릭 시 닫기 미동작**
  - 모달 뒤편의 어두운 오버레이(`fixed inset-0 bg-black/50`) 영역에 `onClick` 이벤트 핸들러가 바인딩 되어 있지 않아, 모달 바깥을 클릭했을 때 모달이 닫히지 않는 동작 상태임. (사용성 차원에서 의도된 강제성인지, 누락인지 확인 필요)

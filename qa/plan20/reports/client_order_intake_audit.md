# Phase 162 — `/projects/intake` 수주 프로젝트 관리 탭 검수 결과

## 검수한 항목
- `수주 프로젝트 관리` 탭 클릭
- 새 프로젝트 등록 버튼 클릭
- 모든 입력 필드 확인
- 필수값 누락 validation 확인
- 납품일 입력/수정 가능 여부 확인
- PM 배정 필드 확인
- 등록 취소 시 데이터 변경 없는지 확인
- 등록 완료 시 데이터 반영 확인

## 정상 확인
- `수주 프로젝트 관리` 탭에 정상적으로 접근 가능함.
- `새 프로젝트 등록` 버튼 클릭 시 프로젝트 등록 폼(모달)이 정상적으로 노출됨.
- 등록 취소: 임의 데이터 입력 후 `취소` 버튼 클릭 시 모달이 정상적으로 닫히며 프로젝트 목록에 데이터가 추가되지 않음을 확인.
- 납품일 필드: `납품 예정일` 필드에 정상적으로 날짜 입력 및 수정 가능함.

## 오류/의심사항
- **[ISSUE-PLAN20-162-001]** 필수값 누락 시 명시적 안내 부족
  - 빈 상태로 `등록하기` 클릭 시 제출이 막히긴 하지만, 시각적인 에러 메시지나 어떤 필드가 누락되었는지에 대한 명확한 UI 피드백이 제공되지 않음. (개선 필요)
- **[ISSUE-PLAN20-162-002]** 등록 모달창 내 'PM 배정' 필드 부재
  - 등록 모달 내에는 'PM 배정' 필드가 존재하지 않음. 등록 이후 프로젝트 테이블 화면의 인라인 드롭다운을 통해 PM을 배정해야 하는 구조로 확인됨. (기획/설계 의도와 일치하는지 확인 필요)
- **[ISSUE-PLAN20-162-003]** 프로젝트 생성 완료 후 보드 반영 검증 한계
  - Subagent 환경 특성상 테이블 인라인 편집과 외부 클릭 이벤트 간 상호작용 과정에서 보드 '착수 전' 컬럼 이동까지 End-to-End 시각적 최종 검증을 완수하지 못하고 중단됨.

# PLAN29 ISSUE MATRIX & BACKLOG (PHASE 369)

## 1. 개요
조사 단계(Discovery, Phase 344~367)에서 발견된 총 16개의 개별 이슈(OBS-29-001 ~ 016)를 근본 원인(Root Cause)별로 병합하고, Plan 29의 후반부인 Patch 단계에서 즉시 수정할지, 아니면 별도의 Plan으로 넘길지 결정하기 위한 통합 백로그를 작성합니다.

## 2. Root Cause 기반 이슈 병합

### [Root Cause A] Zustand Store 핵심 로직 방어막(Guard) 완전 누락
- **관련 이슈**: OBS-29-008, OBS-29-015
- **증상**: 작업자가 브라우저 콘솔을 열고 `updateTaskStatus` 등을 호출하면 UI 가드를 뚫고 남의 업무를 강제 완료시키거나 PM 권한을 탈취할 수 있음.
- **분류**: 권한 격리 및 보안
- **심각도**: **S1 Critical**
- **조치 판정**: **지금 수정** (Phase 378/379에서 즉시 Store 내부 방어막 주입)

### [Root Cause B] 상태 전이 추적(Traceability) 및 비동기 알림망(Notification) 단절
- **관련 이슈**: OBS-29-010, OBS-29-011, OBS-29-016
- **증상**: 승인, 배정, 템플릿 적용 등 중대한 스토어 변화가 일어나도 글로벌 Audit Log에 남지 않으며, 당사자에게 시스템 알림(Notification)이 전송되지 않음. (Store 함수 내부에 로깅/알림 호출 트리거가 누락됨)
- **분류**: 추적 및 데이터 무결성
- **심각도**: **S1 Critical**
- **조치 판정**: **지금 수정** (Phase 379에서 스토어 액션에 로깅/알림 트리거 주입)

### [Root Cause C] JSON Data Handoff 무결성 검증 부재
- **관련 이슈**: OBS-29-001, OBS-29-007
- **증상**: 구버전 데이터나 손상된 JSON을 Import해도 스키마 검증(Zod/Yup 등) 없이 무조건 덮어씌워져 애플리케이션 전체가 뻗을 수 있음.
- **분류**: 데이터 무결성
- **심각도**: **S1 Critical**
- **조치 판정**: **지금 수정** (Phase 377에서 JSON Schema Validation 보강)

### [Root Cause D] 공정 템플릿 반려(Rejection) 로직의 UI 투명화 버그
- **관련 이슈**: OBS-29-004, OBS-29-014
- **증상**: 매니저가 승인을 반려(`REJECTED`)하면, PM 화면에서 해당 템플릿 항목 전체가 증발해버려 반려 사유 확인 및 수정 후 재상신(Revision)이 원천 봉쇄됨.
- **분류**: 핵심 UI/UX 버그
- **심각도**: **S2 Major**
- **조치 판정**: **지금 수정** (Phase 376에서 상태 렌더링 필터 조건 완화 및 재요청 경로 뚫기)

### [Root Cause E] 글로벌 예외 방어막 부재
- **관련 이슈**: OBS-29-013
- **증상**: React 컴포넌트 렌더링 중 오류 발생 시 백지 화면(White Screen) 크래시 유발.
- **분류**: 안정성
- **심각도**: **S2 Major**
- **조치 판정**: **지금 수정** (Phase 371/379 패치 범위에 `error.tsx` 추가)

### [Root Cause F] 물리적 달력 기준 날짜 연산 의존
- **관련 이슈**: OBS-29-012
- **증상**: 납품 소요일 계산 시 주말 및 공휴일을 포함하여 물리적 Calendar Days로 계산하여 실무 일정과 괴리 발생.
- **분류**: 비즈니스 로직
- **심각도**: **S2 Major**
- **조치 판정**: **별도 Plan (사용자 결정 필요)** (Working Days 알고리즘 전면 교체는 공수 큼)

### [Root Cause G] 문서 위생 및 자동 검증 부재
- **관련 이슈**: OBS-29-005, OBS-29-006, OBS-29-003, OBS-29-009
- **증상**: 테스트 스크립트 없음, 일부 문서 깨짐, UI 스타일링 디테일 부족.
- **분류**: 문서 및 테스트 위생
- **심각도**: **S3 Minor**
- **조치 판정**: **지금 수정 (가벼운 건)** 및 일부 별도 Plan
